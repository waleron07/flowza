Flowza API

Swagger для готовых backend-запросов

Здесь собраны уже реализованные эндпоинты из backend: auth, tenants, categories, products, orders, users и health. Базовый сервер по умолчанию настроен на http://localhost:3001.

Bearer auth для защищенных маршрутов OpenAPI 3.0.3 Источник: текущие NestJS controller + DTO
Можно указать любой backend URL. Значение сохраняется в браузере и подставляется в Swagger как основной server.
